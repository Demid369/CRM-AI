## Связка услуг

```
Сайт + SEO ──→ Директ ──→ Метрика / Calltouch ──→ CRM
     │              │              │                  │
     └─ Калькулятор ┴─ Дашборды ────┴─ AI-оптимизация ┴─ Шаблоны КП / договоров
                              │
                    AI-память бренда + чат-бот
```

**Ключевые цепочки:**
- Заявка с сайта или рекламы → CRM → уведомление → КП из шаблона → договор
- Расчёт в калькуляторе → данные в заявку и коммерческое предложение
- AI-память бренда → единые тексты на сайте, в рекламе, боте и документах
- Сквозная аналитика → решения по бюджету Директа и приоритетам SEO
