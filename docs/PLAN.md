# План работ — Сигнификация

Архитектура: `docs/ARCHITECTURE.md`. Таксономия: `docs/taxonomy.md`.
Сайт не верстаем, пока не закрыт пилот семантики и модель данных.

## Фаза 0 — каркас репо и договорённости

- Переименовать GitHub-репо с `CRM-AI` (вручную).
- Зафиксировать бренд, юрлицо, город, контакты, вилку цен — без этого E-E-A-T и оферта пустые.
- Сложить 15–30 реальных рендеров, даже черновых. Витрина «только нейросеть» слабее.
- Выбрать slug и порт на t9 по серверному `ARCHITECTURE.md`, не раньше деплоя.

## Фаза 1 — семантика, не страницы

- Выгрузить паттерны: `{стиль} интерьер`, `{комната} в стиле {стиль}`, `визуализация {комната}`, `{стиль} квартира`, `3d визуализация интерьера`, экстерьер/фасад/барнхаус.
- Кластеризация. Один кластер = один URL.
- Пробить must-комбо Wordstat/Keys.so. В белый список только живые.
- Конкуренты в выдаче: студии, Houzz, Pinterest, статьи журналов. Где реально зайти.
- Стоп: нет 50+ повторяющихся НЧ — режем объём pSEO, усиливаем услуги и кейсы.

**Выход:** таблица `url | cluster | freq | template | index | notes`.

## Фаза 2 — CMS и шаблоны (без генератора)

- Схема сущностей из архитектуры (Style, Room, Project, LandingCombo).
- Три шаблона: хаб, комбо, проект. Коммерческие страницы — руками, не из генератора страниц.
- Правила: нет 4 кадров и уникальных полей → `draft`.
- ЧПУ, каноникал, хлебные, sitemap-чанки, `noindex` на query.
- Пилот в проде: главная-заглушка + о студии + 8–12 хабов + 15–25 комбо + 20–40 проектов.

**Выход:** SSG собирает только `index_policy=index` + `published`.

## Фаза 3 — контент 70%

- Бриф поля: что уникально на проекте / на комбо. Не «переписать абзац».
- Сначала проекты (данные), потом тексты хабов, потом комбо.
- Рендеры под пустые дыры белого списка — своими руками или кампанией, флаг `origin`.
- Проверка: уникальность блоков, одна H1, FAQ по кластеру, внутренние ссылки.
- Не выкладывать 200 URL в один день. Волны по 20–40.

**Выход:** пилот прошёл ручной QA, в Вебмастере без массовых «малоценных».

## Фаза 4 — коммерция

- Услуги, цены, процесс, контакты, политика, оферта.
- Заявка: телефон / Telegram, источник = URL.
- Схема Organization / Offer / FAQ.

## Фаза 5 — генератор (после живой витрины)

- Юнит-экономика кредита **до** кода виджета. Дневной GPU-бюджет в конфиге.
- Квоты 1 гость + 2 после OTP, планировка ×3, водяной знак не снимается.
- OTP: согласие до SMS, капча, лимиты, один ledger на телефон. Заявка студии — отдельный `POST /leads`.
- ЛК: merge гостя, история, «заказать эти ракурсы», пакет только здесь.
- Виджет островом на 2–3 шаблонах, не на legal/ценах/контактах.

## Фаза 6 — масштаб до ~1 000

- Добить белые комбо, где есть кадры.
- Добить карточки проектов (основная масса URL).
- Раз в квартал: вырезать мёртвые, обновить кадры, перелинковка.
- Мониторинг позиций только по белому списку.
- Сравнения стилей и блог-опоры — если пилот дал запросы.

## Порядок «что не делать»

- Не открывать ЧПУ на все фильтры.
- Не запускать OTP и генерации до политики ПДн и поручений шлюзу/GPU.
- Не мешать пользовательские картинки с портфолио студии.
- Не отдавать полный кадр за бесплатный телефон.
- Не плодить гео.
- Не обещать в title «ИИ сделает интерьер» вместо студии.
