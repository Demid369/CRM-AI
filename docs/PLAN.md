# План работ — Сигнификация

Архитектура: `docs/ARCHITECTURE.md`. Таксономия: `docs/taxonomy.md`.
Сайт не верстаем, пока не закрыт пилот семантики и модель данных.

## Фаза 0 — каркас и факты

- Переименовать GitHub-репо с `CRM-AI`.
- Бренд, юрлицо, город, NAP, вилка цен, тексты 152-ФЗ (политика, оферта, согласия).
- Яндекс.Бизнес с тем же NAP. 10 живых упоминаний студии важнее сетки тонких URL.
- 15–30 студийных кадров, разложенных по `(domain, style, room)`. Белый список режется под эти кадры, не наоборот.
- Стек: Next.js SSG + Payload + Postgres. Не Vercel+Supabase как единственный контур ПДн.

## Фаза 1 — семантика

- Паттерны: визуализация {комната}, {комната} в стиле {стиль}, 3d визуализация интерьера/фасада/дома, хаб стиля (не «стиль квартира» отдельным URL).
- Кластер = один URL. Head-запросы закреплены в таблице.
- Пробивка Wordstat/Keys.so. Нет 50+ живых НЧ — режем pSEO.
- «Квартира × стиль» не комбо.

**Выход:** `url | cluster | freq | h1 | title | template | index`. Список фраз и гео: `docs/semantics.md`. Живой Wordstat — под логином Яндекса, не из агента.

## Фаза 2 — коммерция + CMS вместе

Не заглушка. В индекс сразу:

- `/` `/o-studii` `/uslugi/*` `/ceny` `/process` `/dlya-dizaynerov` `/kontakty` `/legal`
- 6–8 хабов стилей + 5–6 комнат + `/eksterier` + 2–3 фасада, где есть кадры
- 8–15 комбо кухня/гостиная с **разными** наборами работ
- 20–40 проектов над порогом (`indexable=true`); остальные в каталоге без индекса
- Генератора нет. Заявка — форма + `Lead`, без кредитов.

**Выход:** SSG из `UrlRegistry`. Критерий пилота — живая заявка, не «25 ЧПУ в sitemap».

## Фаза 3 — контент 70% и волны

- Сначала проекты, потом хабы, потом комбо.
- Волна: родитель в индексе → дети. Не 200 URL/день.
- Следующая пачка 15–25 только если нет всплеска «малоценных».
- Мёртвое комбо: 301 на хаб.

**Выход:** ручной QA + Вебмастер.

## Фаза 4 — генератор (после живой витрины)

- Юрконтур до первой SMS: уведомление РКН, локализация ПДн в РФ, ДПДн шлюзу/GPU, раздельные согласия (ПДн / реклама / трансграничка).
- Юнит-экономика кредита **до** кода виджета. Дневной GPU-бюджет в конфиге. Ориентир интерьера $0.04–0.20/кадр.
- Квоты 1 гость + 2 после OTP, планировка ×3, водяной знак не снимается. Потолок ≤4 бесплатных / номер / 30 дней.
- OTP: согласие до SMS, капча, лимиты, один ledger на телефон. Заявка студии — отдельный `POST /leads`.
- ЛК: merge гостя, история, «заказать эти ракурсы», пакет только здесь.
- Виджет островом на 2–3 шаблонах, не на legal/ценах/контактах. Не в LCP. User-gen `noindex`.

## Фаза 5 — масштаб

- Новые комбо только с кадрами этой пары и пробивкой.
- Новые индексные проекты — только с паспортом. Счётчик URL не цель.
- Раз в квартал: 301 мёртвых, обновить кадры.
- Сравнения и статьи — только по запросам пилота.
- Мониторинг: Вебмастер + GSC + один трекер белого списка.

## Порядок «что не делать»

- Не открывать ЧПУ на все фильтры.
- Не запускать OTP и генерации до политики ПДн, уведомления РКН и поручений шлюзу/GPU.
- Не класть аккаунты только в зарубежный BaaS (локализация 152-ФЗ).
- Не мешать пользовательские картинки с портфолио студии.
- Не отдавать полный кадр за бесплатный телефон.
- Не плодить гео и не открывать `/obekty` / style×object — даже если очередной аудит снова их нарисует.
- Не ставить 600 карточек в индекс ради счётчика.
- Не обещать в title «ИИ сделает интерьер» вместо студии.
- Не ставить виджет на хабы и комбо. Не риелторский опт. Не анимацию в меню пилота.
