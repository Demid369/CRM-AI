# Таксономия: стили, комнаты, объекты

Канон для URL и CMS. Синоним ≠ новая страница. Частотности в пилоте перепроверяем Wordstat / Keys.so — без пробивки не публикуем комбо.

Не страницы: 1к/2к/3к, евродвушка, м², «недорого», «премиум» — фильтры каталога, `noindex`.

## Белый список комбо (стартовая матрица)

Публикуем `style × room` только для must-стилей × must-комнат **и** только если есть ≥4 проекта или готовые уникальные поля. Иначе `draft`.

Приоритет пробивки (сначала эти пары — они кормят НЧ):

1. кухня × {современный, минимализм, сканди, лофт, классика, неоклассика, прованс, джапанди}
2. гостиная × {лофт, современный, классика, минимализм, ар-деко}
3. спальня × {неоклассика, сканди, минимализм, современный}
4. ванная × {современный, минимализм, лофт, классика}
5. квартира × все must-стили
6. дом × {шале, барнхаус, современный, классика, лофт}

Полный декарт 16×9=144 не цель пилота. Цель пилота: 15–25 комбо с живыми кадрами.

## Индексация фильтров каталога

| Действие пользователя | URL | Индекс |
| --- | --- | --- |
| Стиль | `/raboty?style=loft` | noindex → `/stili/loft` |
| Комната | `/raboty?room=kuhnya` | noindex → `/komnaty/kuhnya` |
| Стиль+комната, есть посадочная | `/raboty?style=loft&room=kuhnya` | canonical на `/stili/loft/kuhnya` |
| Стиль+комната, нет посадочной | тот же query | noindex, follow |
| Сортировка, площадь, год | query | noindex |
| Три и больше фасета | query | noindex |

ЧПУ для фильтра без записи `LandingCombo` не генерируем.
