# Варианты продукта и дыры канона

Канон URL/воронки не переписываем. Продукт принят: [`ARCHITECTURE.md`](ARCHITECTURE.md) §1 и §3.2.
Каналы и юнит приняты: [`gtm.md`](gtm.md). Операции ещё идут. Ветку `gtm-cash-track` не мержить — там откат к `E2`.

## Варианты развития (решение)

| Вариант | Вердикт | Почему |
| --- | --- | --- |
| Студия viz по плану | **ядро** | Чек, бренд, E-E-A-T |
| Генератор как лидмагнит | **фаза 4, узкий** | Саджест = бесплатно/ИИ |
| SaaS-подписка на картинки | **нет** | Конкуренция с Flux |
| Маркетплейс визуализаторов | **нет** | Чужой бизнес, 54-ФЗ |
| Блог + партнёрка мебели | **нет как ядро** | Интент «купить кухню» |
| Дизайн интерьера под ключ | **нет в пилоте** | Другая маржа и иск |
| White-label для дизайнеров | **второй оффер** | Ядро Черноземья |
| Риелторский опт | **нет** | Якорь 350 ₽/м² |
| Застройщик | **после кейса ЖК** | Без работы — ложь в меню |
| Конструктор кухни как IKEA | **нет** | Саджест туда и так тянет |
| Эконом `E2` / 500–800 ₽/м² | **нет** | Полка Авито, даже на агрегаторах |
| Четыре лендинга × четыре персоны | **нет** | Риелтор не нужен; застройщик без кейса — нет |

Пилот: **два входа** — частник и `/dlya-dizaynerov`. Генератора нет.

## Закрыто

**Продукт.** Персоны, SKU, пол цены, виджет не на комбо, запрет «ИИ» в H1, протокол правок/сцены, план дизайнера не продаём частнику. `ARCHITECTURE.md` §1, §3.1–3.2, §8.

**Касса.** Фазы G0–G3, Директ/холод/агрегаторы, CAC на R3, слоты 2+1, отказ, предоплата, сезон. `E2` не заводим. `gtm.md`.

## Ещё открыто (ждёт операции / факты)

1. **Саджест vs комбо.** Текст «не конструктор» есть. Нет плана отказа / скролла в Метрике.
2. **Лид в проде.** Норма: Telegram + таблица, SLA 2 ч. Приёмник, антиспам, ночной автоответ — операционка.
3. **Портфолио / NDA.** Порог 15–30 studio. Аноним / фрагмент / меньше комбо, если московские квартиры нельзя показать.
4. **Кто пишет 70%.** Поля есть, редактора нет.
5. **Домашний регион.** Один Вебмастер. Соблазн второй карточки «Москва».
6. **Стоп-кран в проде.** Нормы слотов уже в `gtm.md` §3. Включить после юрлица и живых часов.

## Что не делать, даже если следующий проход предложит

Гео-сетка, style×object, SaaS, 2+6, генератор в H1, виджет на комбо, 600 тонких карточек, конструктор кухни, «дизайн под ключ», риелторский опт, `E2`, четыре персоны, «филиал Москва» без адреса.
